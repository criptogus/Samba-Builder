1. **Memoize `AppItem`**: `AppItem` is used heavily inside `AppList` to render both favorite apps, app collections, and other apps. Because `AppItem` takes `app`, `handleAppClick`, `selectedAppId`, and `enableMultiWindow`, and `handleAppClick` is defined inline as an unmemoized function (`const handleAppClick = (id: number) => { ... }`), `AppItem` components will re-render whenever `AppList` re-renders (e.g. state changes for the search dialog, although `AppList` state changes aren't frequent, parent state changes are). We should use `React.memo` for `AppItem`.
2. **Memoize `handleAppClick`**: In `AppList`, wrap `handleAppClick` with `useCallback` to prevent breaking the memoization of `AppItem`.
