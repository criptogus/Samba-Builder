# Samba Builder 1.14.0

## Correções

- Corrige a seleção de chats pela busca e erros de compilação no console, na lista de modelos locais e no armazenamento de segredos.
- Inclui as skills do construtor de jogos e permite importar skills locais pela tela de extensões.
- A inspeção de programas e skills não instala arquivos. A importação recusa links simbólicos no destino e preserva skills já existentes.
- Atualiza dependências compatíveis, mantendo as versões das APIs que exigem migração, e alinha os pacotes do Storybook.

## Validação

As verificações locais e os resultados dos testes são registrados no commit de integração. Esta alteração não publica uma distribuição do aplicativo.
