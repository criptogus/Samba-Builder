# Samba Builder 1.14.0-beta.2

Versão focada em **fechar o ciclo do trabalho**: o agente agora abre e mescla pull request, sincroniza com o
GitHub, revisa o próprio código com verificação automática, e o app voltou a **se atualizar** — com o estado da
atualização visível na interface.

## Novo

### Atualização de versão
- **Auto-update de volta.** O app consulta as releases deste repositório no GitHub e aplica a atualização, com
  opção de reiniciar na hora ou depois. Antes o switch existia mas não fazia nada.
- **Configurações → auto-update** agora mostra a **versão instalada** e o **estado da última verificação**
  (atualizado, baixando, baixada, falhou com o motivo, ou desligada).

### GitHub no fluxo de trabalho
- **Pull request pela interface**: abrir o PR da branch atual contra a branch principal e **mesclar** depois,
  com confirmação (o merge altera o repositório remoto).
- **Pull request automático ao fim de um push**, atrás de uma opção **desligada por padrão**. Nunca abre a partir
  da branch principal, nunca duplica um PR já aberto, e falha ao abrir o PR não derruba o push.
- **Sincronizar com o GitHub**: baixa do remoto **antes** de enviar, disponível no painel do GitHub e no menu de
  branches. Conflito no download interrompe o envio e entra no fluxo de resolução existente.

### Revisão de código
- **Verificação automática antes do modelo**: seis regras objetivas sobre o diff (HTML não confiável, SQL montado
  por concatenação, chave de serviço no cliente, segredo em variável pública, segredo literal, tabela sem RLS).
  Elas valem mesmo quando o revisor devolve resposta inválida.
- **Cobertura declarada**: o revisor informa quais arquivos revisou; arquivo enviado e não revisado rebaixa o
  resultado para parcial e aparece nomeado no relatório.
- **Posição conferida**: achado cuja linha não pertence ao diff é marcado como "posição não confirmada", em vez de
  exibir uma localização falsa.

### Agente e extensões
- **Skills do projeto**: coloque instruções em `.samba/skills/` (ou na pasta de extensões do usuário) e o agente
  passa a vê-las no contexto, carregando o conteúdo completo só quando a tarefa casa — sem gastar contexto com
  todas as instruções. Skills não concedem ferramentas nem permissões.
- **Guardas de loop**: chamada idêntica repetida vira aviso ao modelo, e ferramentas longas ganham teto de tempo
  com erro claro em vez de travar a sessão.
- **Resultados grandes não são mais descartados**: em vez de truncar e perder, o app guarda o conteúdo íntegro e
  devolve um resumo com o caminho do arquivo.

## Corrigido
- O aviso de contexto cheio ("This chat context is running out") não fica mais preso depois de resumir a conversa.
- Catálogo de ferramentas do agente agora é **gerado do código**, eliminando divergência entre implementação e
  documentação.

## Limitações conhecidas desta versão
- **Atualização automática depende de infraestrutura**: o repositório do canal precisa estar acessível
  publicamente e o macOS exige build **assinado** para aplicar a atualização. Enquanto isso não estiver resolvido,
  a substituição do app é manual (ver `docs/update-runbook.md`).
- **Aviso:** esta é uma versão **beta**; mudanças de comportamento podem ocorrer entre betas.
