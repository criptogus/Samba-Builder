# Samba Builder 1.14.0-beta.14

Versão da fábrica interna (Caminho 1) e da checagem de versão que enxerga beta.

## Novo

### Fábrica
- **Publicação só com o portão verde.** Vercel, Coolify, AWS, função Supabase, comando do agente e ferramenta MCP de deploy passam pelo Security Gate. App fora da fábrica continua livre. Não há waiver.
- **Handoff em um clique.** Com o plano aprovado e o gate verde, o app gera o pacote, commita os recibos, envia o branch e abre (ou atualiza) o pull request com checklist de aceite.
- **Relógio briefing → staging.** Aprovar o plano marca o início; o primeiro deploy de staging marca o fim. A tela mostra os minutos.
- O produto fala em software house Samba, não em primeira hora de loja. Instalador não assinado é só para consultores Samba.

### Atualização
- A checagem periódica consulta a **API de releases deste repositório**, inclusive beta, e ordena por semver. O feed público do Electron ignora pré-lançamento e respondia "no updates" com o zip já publicado.
- O app continua sem se instalar sozinho. No macOS, Verificar atualizações baixa, confere o sha256 e troca o bundle. Nas outras plataformas abre a página da release.

## Limitações conhecidas desta versão
- Builds **não assinados**. A trilha de assinatura Apple/Azure fica para quando as credenciais existirem.
- O piloto de um dia útil com cliente real ainda não rodou; o post-mortem em `docs/samba-factory/postmortems/` não inventa duração.
- **Aviso:** esta é uma versão **beta**; mudanças de comportamento podem ocorrer entre betas.
