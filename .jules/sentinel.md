## 2026-09-21 - Unmasked API Key Input Fields\n**Vulnerability:** API key input fields (e.g., in `ApiKeyConfiguration`) were rendered as plain text (type="text"), exposing sensitive credentials to shoulder surfing or accidental screen sharing exposure.\n**Learning:** The default `Input` component does not mask input. Explicit `type="password"` must be added when dealing with sensitive information like API keys.\n**Prevention:** Always verify that input fields handling secrets, tokens, or passwords explicitly set `type="password"`.
