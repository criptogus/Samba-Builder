## 2024-11-20 - Add explicit aria-labels for buttons inside TooltipTrigger
**Learning:** Icon-only components (like `<Button>`) used as `render` props inside `@base-ui/react/tooltip`'s `<TooltipTrigger>` do not inherit accessible names from their `<TooltipContent>` natively in this app's implementation. A screen reader reading the focused trigger button might ignore the tooltip content and read it as empty.
**Action:** Always provide an explicit `aria-label` directly on the `<Button>` component passed to the `<TooltipTrigger render={...}>` prop. If the `<TooltipContent>` uses a translation key, use the same translation key for the `aria-label` (e.g., `aria-label={t("settings:ai.editProvider")}`). If it's a hardcoded string, use the exact same string to ensure consistency.
