## 2026-09-23 - Custom hook function references breaking list virtualization/memoization
**Learning:** Custom hooks that return functions (like `useOpenApp`) can silently break `React.memo` optimization in list items if the returned function is not wrapped in `useCallback`. Even if the list item itself is memoized and its props (like derived boolean flags) are stable, receiving a new function reference from the parent container on every render will cause a full list re-render, creating an O(N) performance penalty on state changes.
**Action:** When inspecting components that render large lists (like `AppList`), always trace the provenance of callback props passed to memoized items. Ensure that any custom hooks generating these callbacks are using `useCallback` internally to preserve reference equality.
