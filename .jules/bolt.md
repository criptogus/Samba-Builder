## 2024-06-25 - Prevent Full List Re-renders on Interaction
**Learning:** In this codebase, list components frequently pass inline functions or globally tracked IDs directly to their item children. This causes the entire list to re-render whenever the global state changes (e.g. selection) or a parent component re-renders. We observed this in `apps.tsx` where an entire list of `AppShowcaseCard`s would re-render when interacting with the selection checkbox, because the components were not memoized and they were being passed inline functions (like unmemoized `handleToggleSelect` or callbacks from `useOpenApp`).
**Action:** Always wrap list items like `AppShowcaseCard` in `React.memo`. When dealing with selections, pass derived boolean flags (e.g., `isSelected={selectedAppId === app.id}`) instead of the globally tracked ID itself. More critically, ensure all callbacks passed as props to these memoized list items (like `handleToggleSelect` or callbacks returned from custom hooks like `useOpenApp`) are wrapped in `useCallback`. Failure to wrap these callbacks will silently break the `React.memo` shallow comparison, defeating the performance optimization.
