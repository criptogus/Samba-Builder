## 2024-03-24 - Interactive Divs with Nested Buttons
**Learning:** In React applications, developers often wrap complex visual elements containing multiple icons or logos inside a clickable `div` using `onClick`. To make it accessible, converting the outer `div` to a `<button>` is the correct approach. However, if the inner elements contain decorative `<button>` tags (often used purely for styling or as visual badges), this results in nested interactive elements, which causes severe issues for screen readers.
**Action:** When converting a clickable wrapper `div` to a semantic `<button>`, always inspect the inner children for existing interactive tags (like `<button>`, `<a>`, or `<input>`). If those inner interactive elements are purely decorative or serve the same function as the wrapper, they must be converted to non-interactive tags (like `div` or `span`) and given `aria-hidden="true"` to ensure a single, unified accessible target.
